# Дизайн: гейт конвертации «размер ИЛИ разрешение»

Дата: 2026-11-25
Статус: утверждено пользователем

## Проблема

Гейт модуля `convert-video` учитывает только размер: файл меньше `min_file_size_mb` пропускается целиком, разрешение даже не определяется. Маленький файл высокого разрешения (например, 300 МБ 3840x2160) остаётся без конвертации и уменьшения.

## Требования

- Файл конвертируется, если **размер ≥ `min_file_size_mb` ИЛИ длинная сторона > `max_resolution`**.
- Пропуск — только если оба условия ложны (маленький И разрешение не выше порога), с логом причины: «📉 Пропуск: <N> МБ, разрешение не выше <max_resolution>: <имя>».
- Триггер «по разрешению» конвертирует с уменьшением (обычный путь `Get-ScaledDimensions`); триггер «по размеру» — без изменения разрешения (как сейчас).
- Нераспознанные размеры видео → ScaleWidth/ScaleHeight = 0 → решение откатывается к «только размер» (маленькие файлы с нераспознанным разрешением пропускаются, как раньше).
- Отсутствие видеопотока → ошибка и return (как сейчас; теперь проверяется и для маленьких файлов, которые раньше не проверялись вовсе).
- `min_file_size_mb` и `max_resolution` — семантика ключей не меняется.

## Изменения по файлам

### 1. `includes/Test-ConversionNeeded.ps1` (новый)

Чистая функция-предикат, паттерн «функция = файл»:

```powershell
Test-ConversionNeeded -FileSizeMB <double> -MinFileSizeMB <int> -ScaleWidth <int> -ScaleHeight <int> → $true/$false
```

`$true`, если размер ≥ порога ИЛИ оба Scale > 0. Параметры Scale не обязательны (при `$null` → 0, без prompt — как в `Get-ScaledDimensions`).

### 2. `auto-converter.ps1`

В блоке `convert-video` вызов `Get-FfmpegConversionStrategy` и расчёт `$scale` переезжают до гейта; гейт — одна строка с `Test-ConversionNeeded`; лог пропуска отражает обе причины. Порядок остальных модулей (extract-subtitles, copy-to-destination и т.д.) не меняется.

### 3. `README.md`, `docs/README_ru.md`

Формулировка гейта: конвертация выполняется при превышении порога размера **или** разрешения.

## Не входит в объём

- Новые ключи конфига; изменение порогов по умолчанию; audio/subtitle-модули.
